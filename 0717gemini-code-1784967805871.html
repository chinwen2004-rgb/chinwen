中小學教師暑期進修課程

地震學、地球物理與
AI／Agent 輔助教學實作

本課程專為中小學教師設計，結合地震學實務與現代數位工具（AI Agent、GitHub、Vercel、Google GAS），協助教師將真實科研資料轉化為可帶回課堂的互動教材與專題。

2026/7/17 起 (每週五)
課程時數
共 6 週，每次 4 小時
招生對象
中小學現職教師
核心精神
教學相長・動手實作

課程核心目標

1

地震學與資料分析

建立基本理論，學會使用真實地震資料進行分析，並轉化為中小學易懂的教學活動。

2

AI Agent 與現代工具

掌握 opencode、Antigravity CLI、Hermes agent、GitHub、Hugging Face 與 Vercel 工具。

3

雲端與自動化流程

運用 Google GWS 與 GAS 打造教學自動化、資料收集與作品展示流程。

4

野外觀測與作品產出

進行野外或簡易地震儀實驗，最終產出一份完整、可直接應用的地震教學作品。

WEEK 01 • 2026/07/17

課程介紹、帳號申請、軟體安裝與工作流程建立

環境建立工作坊

本週學習重點

  • 說明課程目標與學習地圖，建立個人學習目標。
  • 建立 Google Drive、GitHub、Hugging Face、Vercel 帳號。
  • 測試 Google Forms、Sheets 與 Google Apps Script (GAS)。
  • 安裝或導覽 Git, VS Code, Python, Node.js, opencode, Hermes agent 等 CLI 工具。
  • 瀏覽 IRIS InClass 地震學教學資源庫。

作業 1：完成個人數位學習工作區

繳交 Drive 資料夾截圖、GitHub repo 連結、GAS 測試表單連結與 100-200 字個人目標。

檢核重點：
帳號至少 3 項完成 GitHub 含 README GAS 測試執行成功
WEEK 02 • 2026/07/24

地震儀、加速度、地震動與震度

數據感測與實驗

本週學習重點

  • 探索地震儀紀錄原理：地面搖晃如何被物理儀器量化。
  • 理解震度與加速度（PGA）之間的物理與數學對應。
  • 運用 IRIS ground-shaking 活動與三分量加速度計實作。
  • 使用手機或 USB 感測器進行即時搖晃數據採集。

作業 2：完成簡易震動觀測活動

繳交手機/感測器數據紀錄、Google Sheets 圖表、學生學習單與 200 字教學說明。

檢核重點：
含實測/模擬震動資料 呈現震動強弱變化圖表 區分感覺與儀器量測
WEEK 03 • 2026/07/31

P-S 到時差、旅行時間曲線與震央定位

空間幾何與波形解密

本週學習重點

  • 辨識三分量地震紀錄中的 P 波與 S 波訊號。
  • 利用 P-S 到時差與走時曲線估算測站震央距。
  • 操作 IRIS 震央定位教學活動，繪製三測站距離交會圖。
  • 結合 Python 或 Sheets 進行自動化定位計算。

作業 3：完成震央定位教學範例

繳交 3 測站 P/S 到時表、震央距計算、三測站定位圖與 GitHub/Sheets 連結。

檢核重點：
正確標示至少 3 站波相 畫出 3 個距離交會圓 解釋需 3 站之物理原因
WEEK 04 • 2026/08/07

課本第 4 章精讀與真實地震波形資料

理論深化與波形研析

本週學習重點

  • 精讀《Introduction to Earthquake Seismology》第 4 章。
  • 使用 jAmaSeis 或即時波形工具連結真實地震網。
  • 載入 Hugging Face Dataset 進行專業波形分析。
  • 將高等地震學理論進行「中小學教學轉化」。

作業 4：完成第 4 章導讀與波形分析報告

繳交 1 頁中文導讀、真實波形圖（含波相標示）、3 個教學重點與 200 字反思。

檢核重點：
整理課本重點概念 呈現真實波形圖標示 明確區分中小學/大學版本
WEEK 05 • 2026/08/14

規模、震度、場址效應與建物反應

防災應用與 Web 部署

本週學習重點

  • 嚴謹釐清「地震規模 (Magnitude)」與「震度 (Intensity)」差異。
  • 探討軟弱地盤造成的場址放大效應與共振現象。
  • 運用 Vercel 或 GitHub Pages 建立地震防災互動網頁。
  • 設計互動題目與學生自動回饋機制（結合 GAS）。

作業 5：完成地震防災互動網頁初版

繳交已部署網頁連結、規模/震度比較圖、場址效應說明與學生互動試題。

檢核重點：
網頁可公開瀏覽 圖文說明規模與震度 具備至少 1 題互動設計
WEEK 06 • 2026/08/21

野外實驗、成果整合與教案發表

實地觀測與成果發表

本週學習重點

  • 進行校園野外地震儀/微動觀測（或替代之手機感測器備案）。
  • 整合 IRIS Teachable Moments 案例強化教案設計。
  • 運用 Hermes Agent 與 GitHub Pages 打包個人教學成果集。
  • 進行 5–7 分鐘期末成果簡報與同儕專業交流。

作業 6：期末教學作品與發表

繳交完整教案、學習單、教師手冊、數位作品連結、簡報與 300 字總反思。

檢核重點：
概念明確且學生可操作 數位作品可正常執行 完成 5-7 分鐘發表

開學後「地球物理學」延伸共用

Week 1 工具環境

延伸至 GitHub / 資料分析自動化工作流

Week 2 地震動/震度

Week 5 場址效應

Week 6 野外實驗

進行專業儀器操作與專題研究
